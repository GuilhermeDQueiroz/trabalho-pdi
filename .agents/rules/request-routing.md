# Request Routing - Sistema PDI

> Mapeamento automático de requisições e seleção de agentes especialistas.

---

## 1. Classificação de Domínio

| Domínio Detectado | Agente Recomendado | Habilidade Principal |
|---|---|---|
| Algoritmos de PDI, filtros, convolução, matemática | `@especialista-pdi` | Python puro, matrizes, transformações |
| Interface, Vuetify, Canvas, ApexCharts, TypeScript | `@frontend-specialist` | Vue 3, layout monocromático, ponta de prova |
| Arquitetura, pipeline completo, testes, execução | `@orchestrator` | Visão sistêmica e integração ponta a ponta |

---

## 2. Formato de Resposta

Ao assumir a persona de um especialista:
```markdown
🤖 **Applying knowledge of `@[agent-name]`...**

[Resposta especializada]
```
